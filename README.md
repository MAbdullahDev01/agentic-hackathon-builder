# Agentic Hackathon Builder

A multiagent full stack website to research, develop an idea and bring it to life.

Quick execution to build a demo quicker within hackathon's time limit

## Agents:
1. Research agent:
  - Research a given topic.
  - Generate detailed research reports.
  - Include a TL;DR section.
  - Document all sources used.
  - Verify sources and supporting evidence.
  - Cross-reference information across sources.
  - Identify requirements, resources, and dependencies.
  - Generate structured reports.
  - Save and retrieve previous research.
  - Generate research plans before investigating.
